隐私：存了什么、什么会离开本机、怎么彻底删除

Job Radar 是跑在你自己机器上的单用户工具：没有账号、没有遥测、没有更新检查、没有托管服务，页面运行时也不加载任何外部资源（字体已内置）。 本页列出它存了什么、哪些外部服务可能收到你的一部分数据，以及怎么全部删除。这是技术说明，不是法律意见。

存了什么，存多久

Section titled “存了什么，存多久”
数据 位置 保留
你的画像（me.yaml：技能、年限、语言、简介；preferences.yaml：目标职位、城市、薪资底线、排除的公司和关键词） 宿主机 data/profile/ 直到你删除
画像的每个历史版本（完整 YAML 文本） 数据库表 profile_snapshots 直到你删除数据库；没有清理任务
配置，包括你自己的评分标准（ai.yaml） data/config/，编辑器备份在 data/config/.backup/ 编辑器备份有上限；迁移备份不会自动清理
申请、下一步、备注、收藏及收藏备注 数据库 直到你删除数据库（取消收藏时收藏备注一起删除）
各渠道原样的原始岗位，以及未解析的职位提醒邮件（整封） 数据库表 raw_postings 直到你删除数据库
邮件元数据（Message-ID、发件人地址、IMAP UID） 数据库表 email_messages 直到你删除数据库
AI 结果（评分及理由、翻译、拆解、信号、陷阱标记、带引文的每周建议）和 AI 用量记录（模型、token、耗时） 数据库 直到你删除数据库
已发出的 Telegram 消息（内容和消息 id）、控制请求及结果 数据库 直到你删除数据库
runner 心跳 数据库 24 小时
数据库备份 data/backups/ 自动：14 份日备、8 份周备；手动备份不会被清理。已删除的记录在旧备份里还会留着，直到这些备份被删掉
给 resume-kit 的 JD 导出 data/exports/jd/ 直到你删除
日志 容器日志（轮转）、data/logs/（轮转）、macOS 上的 ~/Library/Logs/job-radar/ 轮转
密钥：Gmail 应用密码、Telegram token 和 chat id、API key .env 直到你删除
LinkedIn 登录态（仅当你用登录会话时） .auth/ 直到你删除
AI 命令行调用的临时文件 $TMPDIR/jr-codex-*、jr-claude-* 每次调用后删除（进程被强杀可能残留）

上面的数据库表目前没有自动保留期：原始岗位、未解析邮件、通知、控制请求和画像快照会一直留到你删除数据库。data/ 包含上面的全部内容， 请不要放在云同步盘或共享目录里。备份文件和导出的 JD 文件含有个人数据。

什么会离开本机

Section titled “什么会离开本机”
谁 发什么 何时 怎么停止
你使用的 AI 提供方：OpenAI（codex 命令行）、Anthropic（claude 命令行或 API）、DeepSeek 或小米 MiMo（API，默认关闭） 评分： 画像摘要、技能和年限、语言等级、目标职位、目标城市、工作方式、远程范围、级别、薪资底线、合同偏好、排除的公司、排除的关键词、你自己的评分标准，加上岗位描述。每周建议： 你标记过的岗位（感兴趣、准备中、已申请、面试中、offer、忽略）及其状态，加上你的偏好。翻译、拆解、信号、陷阱检查： 只有岗位文本。你的居住城市和签证状态（me.yaml）、备注和申请备注不会发送。 每一轮 关掉该提供方（ai.yaml 里 enabled: false，或“设置 → AI”），不安装它的命令行、不填它的 key；每周建议用 schedule.yaml 的 suggest.enabled 关掉
招聘网站和接口：Arbeitsagentur、Indeed、LinkedIn、StepStone、XING、经 JSearch 的 Google Jobs、公司招聘页、Bright Data、Apify 你的搜索关键词和城市，以及来自你 IP 地址的请求（LinkedIn 登录会话：以你登录的账号发请求） 每一轮 在“来源”页关掉该通道
Tavily 或 Brave（招聘页发现） 形如“关键词 jobs 城市”的搜索词 每天，且仅在有 key 时 不设置 key
Google（Gmail，IMAP） 用应用密码登录并读取一个标签 每一轮 关掉 Gmail 通道；撤销应用密码
Telegram 职位名、公司、分数、AI 一句话摘要、提醒、健康告警，以及用“定制简历”按钮时的命令文本 推送时 Telegram 默认关闭（notify.yaml），保持关闭即可
终端里的 claude（resume-kit /tailor） 你的完整简历和岗位描述，仅当你自己运行这条命令时 只在你运行时 不运行它

不会向项目维护者或任何统计服务发送任何东西。

AI 提供方怎么保存

Section titled “AI 提供方怎么保存”
  • 订阅命令行（codex、claude）适用你的 ChatGPT 或 Claude 订阅的消费者条款。Job Radar 启动它们时不保存会话，但提供方怎么使用内容（例如用来改进模型） 取决于你账号里的设置：在 ChatGPT（设置 → 数据控制）里查看“为所有人改进模型”，在 Claude（设置 → 隐私）里查看“帮助改进 Claude”，不想被用就关掉。
  • API key 适用提供方的商业或 API 条款，通常默认不会拿你的数据训练；请阅读你所用提供方的条款。
  • DeepSeek 和小米 MiMo 由中国境内运营，发给它们的数据受中国法律管辖。它们默认关闭，只有接受这一点时才打开。
  • Telegram 把 bot 消息存在它的服务器上，不是端到端加密。能访问该聊天、你的账号或 bot token 的人都能读到。
  • Gmail 应用密码能访问整个邮箱，不只是 Job Radar 读的那个标签。建议用一个只接收职位提醒的专用邮箱，不用时撤销密码。

已打开且可用的提供方（“设置 → AI”、pnpm run doctor）就是可能收到你的画像摘要和岗位文本的服务。

彻底删除

Section titled “彻底删除”

不再使用 Job Radar，或想清除求职痕迹时这样做。不可撤销。

  1. 先备份要保留的东西（比如 data/profile/ 和 data/config/），复制到项目目录之外。
  2. 卸载这套安装： 停掉宿主机 AI worker，删除容器，删除数据库卷 jobradar-pg（这一步才会删掉所有已存的岗位、申请和备注），删除 data/、.env、.auth/ 和代码目录。 命令见卸载。
  3. 备份和别处的副本： 删除 data/backups/（随 data/ 一起），以及你复制到其他磁盘或云盘的备份，还有导出的 JD 文件和定制好的简历（data/exports/、resume-kit 的输出目录）。
  4. 日志和临时文件： macOS 上的 ~/Library/Logs/job-radar/，以及被强杀的 AI 调用可能留下的 $TMPDIR/jr-*。
  5. 账号： 撤销 Gmail 应用密码（Google 账号 → 安全 → 应用专用密码）；在 BotFather 里删除 Telegram bot（/deletebot）并清空聊天；退出 LinkedIn 会话； 删除只为它创建的 API key（Anthropic、DeepSeek、MiMo、JSearch、Tavily、Bright Data、Apify）。
  6. AI 提供方那边： codex 和 claude 命令行不会保存来自 Job Radar 的本地会话，但你的提供方账号可能按你的套餐保留对话历史或用量记录：需要的话请在那边删除。

当前版本的网页界面没有“删除单个岗位或申请”的功能。删除数据库卷（第 2 步）是清除已存岗位和备注的受支持方式；想继续使用的话，之后用一个空库重新开始。
